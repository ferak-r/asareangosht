# اثر انگشت

سامانه فارسی مدیریت پروژه، عملیات و مالی برای کارگاه دکوراسیون چوبی «اثر انگشت».

## نسخه اولیه

- ورود با ایمیل یا موبایل، نقش‌های دسترسی و مدیریت کاربران توسط مدیر سیستم
- مدیریت کاربران، اشخاص و دپارتمان‌ها
- پروژه، قرارداد، آیتم، زیرآیتم و تسک
- هزینه، درآمد، حساب، انتقال، حقوق، طلب/بدهی و چک
- گزارش‌های مالی و پروژه، خروجی Excel/PDF و پنل مشتری

## پیش‌نیازها

- PHP 8.3 یا جدیدتر
- Composer 2
- Node.js 22 یا جدیدتر
- MySQL 8 / MariaDB 10.6 یا جدیدتر

## راه‌اندازی محلی

```bash
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate --seed
npm install
npm run build
php artisan serve
```

صفحه `/financial` ثبت سندهای هزینه، درآمد، حقوق، طلب و بدهی را انجام می‌دهد. هر سند می‌تواند چند ریزپرداخت و چند تخصیص داشته باشد. انتقال حسابی دو رکورد متوازن `in/out` می‌سازد و وصول یا برگشت چک، وضعیت ریزتراکنش مرتبط را به‌ترتیب `cleared/reversed` می‌کند. ابطال سند مالی فقط برای مدیر سیستم مجاز است.

## گزارش، پنل مشتری و زمان‌بندی

- `/reports` گزارش اسناد مالی، حساب‌ها، پروژه، چک و حقوق را با فیلتر مشترک صفحه/CSV/چاپ ارائه می‌کند.
- خروجی CSV دارای UTF-8 BOM است و در Excel باز می‌شود؛ نسخه چاپی برای Save as PDF مرورگر آماده شده است.
- مشتری فقط پروژه متصل به شخص خودش و report keyهای فعال‌شده توسط مدیر را می‌بیند.
- پیوست پروژه روی دیسک private ذخیره و فقط از route کنترل‌شده دانلود می‌شود.
- تغییر موجودیت‌های اصلی و خروجی گزارش در `audit_logs` ثبت می‌شود.
- برای اعلان سررسید تسک، scheduler سرور باید هر دقیقه `php artisan schedule:run` را اجرا کند؛ فرمان داخلی هر روز ساعت 08:00 اعلان‌های دو روز مانده را می‌سازد.

تست‌ها:

```bash
php artisan test
php artisan tasks:send-due-reminders
```

تنظیمات پایگاه‌داده را پیش از اجرای migration در `.env` وارد کنید. رابط کاربری فارسی و راست‌چین و همه مبلغ‌ها تومانِ بدون اعشار هستند.

## حساب آزمایشی و اجرای مرحله اول

اجرای `php artisan migrate --seed` نقش‌های `admin`، `employee`، `department_manager`، `project_manager` و `customer` را می‌سازد. پیش از اجرای seed، حساب مدیر را فقط از طریق `.env` تعیین کنید:

```text
INITIAL_ADMIN_NAME="مدیر سامانه"
INITIAL_ADMIN_EMAIL=your-admin@example.com
INITIAL_ADMIN_MOBILE=09xxxxxxxxx
INITIAL_ADMIN_PASSWORD=یک-رمز-قوی-و-اختصاصی
```

هیچ رمز پیش‌فرضی در repository وجود ندارد. ثبت‌نام عمومی عمداً غیرفعال است؛ فقط مدیر سیستم در `/users` کاربر جدید می‌سازد.

پس از اضافه‌شدن پکیج جدید به `composer.json`، روی یک کپی تازه از پروژه این دستور را اجرا کنید تا lock file نیز به‌روز شود:

```bash
composer update
php artisan migrate:fresh --seed
php artisan serve
```
